# 🤖 AI Customer Support Agent

An AI-powered customer support chatbot for e-commerce platforms built using **React**, **FastAPI**, and **Google Gemini AI**.

This project provides intelligent customer assistance for:
- Product inquiries
- Shipping information
- Refund & return policies
- Payment & EMI support
- Context-aware conversations
